## 📋 Quick Setup (5 Minutes)

### 1. Go to Google Search Console
🔗 https://search.google.com/search-console

### 2. Add Your Website
```
https://new-koshi-a-c-three.vercel.app
```

### 3. Get Verification Code
Google will give you something like:
```html
<meta name="google-site-verification" content="ABC123XYZ..." />
```

### 4. Add Code to Your Site
Edit `frontend/public/index.html` line 7:
```html
<!-- REPLACE THIS LINE: -->
<!-- <meta name="google-site-verification" content="YOUR_VERIFICATION_CODE_HERE" /> -->

<!-- WITH YOUR ACTUAL CODE: -->
<meta name="google-site-verification" content="ABC123XYZ..." />
```

### 5. Deploy
```bash
cd bus-booking/frontend
npm run build
git add -A
git commit -m "Add Google verification"
git push origin master
```

### 6. Verify & Submit Sitemap
- Wait 2 minutes for deployment
- Click "Verify" in Google Search Console
- Submit sitemap: `https://new-koshi-a-c-three.vercel.app/sitemap.xml`
